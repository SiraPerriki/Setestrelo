# Brief de arte y UX

## Direccion visual

Poetica, delicada, viva y muy clara de leer.

La referencia no es una landing grande ni un dashboard. La referencia es una pequena herramienta ritual donde el cielo ocupa casi todo y la UI se mantiene ligera, pero con suficiente senal visual para orientar rapido la atencion.

## Sensacion

- Intima
- Suave
- Brillante
- Ordenada
- Viva
- Clara de un vistazo

## Criterio de claridad

Disenar pensando tambien en personas con TDAH implica:

- un foco principal evidente en cada pantalla
- menos paneles simultaneos con el mismo peso
- acciones primarias muy distinguibles
- color y forma usados para guiar, no solo para decorar
- estados y modos muy visibles

## Layout recomendado

Desktop:

- toolbar superior fina
- tabs de cielos tipo archivador
- gran area de cielo
- un unico panel lateral dominante segun el estado
- modo diario a pantalla completa cuando se activa

Movil:

- toolbar compacta
- cielo como protagonista
- panel de edicion en bottom sheet o modal
- diario como vista unica vertical

## Recursos visuales

- Gradientes profundos
- Nebulosas tenues pero diferenciadas por cielo
- Particulas flotantes
- Estrellas con halos suaves
- Titileo leve y asincronico
- Lineas rectas de constelacion, muy finas y luminosas
- Estrella fugaz ocasional

## Paleta sugerida

Base:

- Azul medianoche
- Azul tinta
- Crema estelar

Acentos para jerarquia:

- Dorado suave para accion principal
- Rosa nebulosa para paneles protagonistas
- Violeta para seleccion y tabs activas
- Verde menta para informacion de estado
- Celeste empolvado para ayudas y lectura secundaria

La interfaz puede ser dark, pero no debe quedarse en gris/azul. La paleta debe dirigir la mirada.

## Tipografia

Recomendacion:

- serif poetica o display delicada para el nombre del producto y algunos titulares
- sans limpia y pequena para botones, controles e inspector

Los textos funcionales deben ser mas pequenos que en el prototipo inicial.

## Elementos minimos a disenar

- toolbar compacta
- tabs de cielos tipo archivador
- 3 formas base de estrella
- 4 colores base
- 4 atmosferas de cielo claramente diferenciadas
- 1 conjunto de particulas
- 1 linea de constelacion fina y sutil
- 1 estado de seleccion de estrella
- 1 estilo de diario tipo libreta o bloc

## Microcopy sugerido

Titulo:

- `Atlas de Luz`

Botones:

- `＋ Nuevo cielo`
- `✦ Nueva estrella`
- `☄ Constelar`
- `📝 Diario`
- `❔ Ayuda`
- `⬇ Backup`

Placeholder:

- `Ej. Casa tibia`
- `Describe con un poco mas de detalle la sensacion o el deseo que quieres guardar.`

Mensajes de sistema:

- `Tu estrella ha nacido.`
- `Has unido una nueva constelacion.`
- `Este cielo esta lleno de luz.`

## Comportamiento UX

- El cielo debe verse de un vistazo en desktop.
- La toolbar no debe competir con la escena.
- La creacion de estrella debe sentirse sincronizada.
- El titileo debe ser suave y casi subconsciente.
- El modo de constelacion debe sentirse claro y manual.
- La seleccion de estrella debe abrir lectura antes que edicion.
- El diario debe sentirse como otra superficie del mismo universo, no como una pantalla administrativa.

## Duracion orientativa de la secuencia

- Salida del polvo estelar: `900-1400 ms`
- Llegada y encendido: `400-700 ms`
- Total ideal: `1.5 s - 2.2 s`

## Regla creativa importante

Cada decision visual debe reforzar esta idea:

el cielo es tuyo, vive contigo, y el diario te deja volver a tus notas con calma.
